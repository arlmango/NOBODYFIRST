# Addresses printed in forge test traces

These are **Foundry in-process test addresses** (forge's in-memory EVM). They are not on any network and are not the Anvil addresses in `anvil-deploy2/`.

Source files (all in this folder, generated by `scripts/run-stage2.sh`):
- `setup-trace-happy.log`: `forge test --match-test test_HappyPath_ExactBalancesRunStateEventsNoPermits -vvvvv`
- `setup-trace-wiring.log`: `forge test --match-test test_Wiring_DistinctNonZeroAddressesWithCode -vvvvv`
- `latefail-trace.log`: `forge test --match-contract Level1LateFailure -vvvv`

`-vvvvv` is used for the setUp traces because `-vvvv` does not print setUp.
