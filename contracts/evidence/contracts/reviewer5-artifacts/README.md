## What each file proves, and what it does not

- **`latefail-anvil-receipt.json`**: the receipt of transaction `0x9d3ffbf7…d987a` on the reviewer's local Anvil (chainId 31337): `status` 0x0 (reverted), `logs` empty, `blockNumber` 0x6, `gasUsed` 0x6ae2e, `from`/`to` as in the file, and the revert data (custom error 0x8c202106). **Does not prove** the state after the transaction (balances, run fields, permits, snapshot): none of that is saved. The Anvil state is gone.
- **`latefail-anvil-castrun.log`**: the call trace of the same transaction (`cast run`). It shows `execute`, the first NPC's `release` → `GameItems::transferFromNpc` → `ItemMoved(0→1, KEY, 1)`, then the second NPC's `release` reverting `LateFailInjected(runId, 0, 1)` that propagates out of `execute`. **Does not prove** which address is which role on its own (the trace has no labels); the second release is `LateFailNpcB` only by reading `R5FixtureDeployer.sol.txt` and the revert data. It also does not show the post-state.
- **`latefail-tx.txt`**: the transaction hash only.
- **`mutation-results-round1.txt`**: the reviewer's round-1 result per mutant (first 64-test suite): 31 mutants, 16 killed, 15 survived (M01, M03, M06, M08, M09, M10, M11, M12, M13, M25, M26, M27, M29, M30, M31). **Does not prove** why any mutant survived, and does not contain per-mutant forge output.
- **`mutation-results-round2.txt`**: the reviewer's round-2 result per mutant (final 77-test suite, independent re-run): 31 mutants, 30 killed, 1 survived (M06). The file lists killing tests for killed mutants. **Does not prove** the M06 reasoning (that is the reviewer's analysis, recorded in the reviewer's report and summarised in `GUARANTEES.md` section 5). The file has no date line; the mtime is the only date evidence.
- **`mut.py`, `mut2.py`, `mutR2.py`**: the mutant definitions and the driver scripts. They contain hard-coded scratch paths and call forge with `C + "/.tools/bin/forge"`. **Do not run them from this folder** (running forge writes to the external cache; see `GUARANTEES.md` section 8). They are kept as the record of what each mutant changed.
- **`R5FixtureDeployer.sol.txt`**: the reviewer's scratch deployer that builds the fault world for the Anvil replay (NPC B = `LateFailNpcB`). It is **not** part of the repository, is not in `src/` or `test/`, and is not compiled (the `.txt` extension). **Does not prove** that the replay can be reproduced from the repository alone; it cannot be.
