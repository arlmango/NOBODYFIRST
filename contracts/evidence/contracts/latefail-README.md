## Fixture (from the test headers, `test/Level1LateFailure.t.sol` lines 1-40 and `test/harness/LateFailNpcB.sol`)

- GameItems, NPC_A, NPC_C and AtomicCoordinator are the unmodified production contracts, deployed with their production constructors.
- Only NPC B differs. `test/harness/LateFailNpcB.sol` inherits production NPC_B and overrides one function:
  - `LateFailNpcB.release` reverts `LateFailInjected(runId, aKey, bKey)`;
  - `LateFailNpcB_Final.isGoalSatisfied` returns false (the coordinator then reverts `GoalNotSatisfied(1)`).
- Header quote: "No settlement logic is copied, no switches/flags; the fault is unconditional."
- The wiring is built in the test with `vm.computeCreateAddress` (not by `Level1Deployer`, which "can only deploy production NPC_B"). Every created address is asserted equal to its prediction.
- Control: the same wiring with production NPC_B solves the level, so "the wiring itself is sound and the failures below are caused by the injected fault only."

## Fields compared (`test/harness/Level1TestBase.sol`, `FullState`, `assertStateEq`)

- `items.balanceOf(runId, A|B|C, KEY|COIN)` (6 values)
- `items.isGranted(runId)`
- `npcA/npcB/npcC.permitOf(runId)` = `(offerId, snapshotHash, planHash, active)`, for each of A, B, C
- `coord.runOf(runId)` = `(owner, active, solved, nonce)`
- `coord.currentSnapshotHash(runId)`

`assertStateEq` asserts that each of these is equal before and after the call. Not stated in the files: any field beyond this list.

## Boundary and event caveat (quoted from the header)

- "this proves EVM revert atomicity for THIS call path (AtomicCoordinator.execute -> npcA.release -> GameItems.transferFromNpc -> npcB.release / isGoalSatisfied revert) and THESE state fields. It says nothing about other call paths, other contracts or off-chain state."
- "trace events of a reverted frame are debug output, NOT persisted events." The tests count logs emitted inside the reverted frame with `vm.getRecordedLogs()`, which "ALSO captures LOG opcodes of reverted frames". "Receipt-level non-persistence (a reverted tx has no logs) follows from EVM semantics and is not observable in this in-process test."
